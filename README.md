# Pocket Time

مذكرة جيب رقمية لتنظيم اليوم بأسلوب Time Blocking: بسيطة، سريعة، بالعربية والإنجليزية، ومهامك مشفرة تشفيرًا حقيقيًا من طرف إلى طرف بين الآيفون واللابتوب.

**الرابط:** https://claude.ai/artifact/QVw5kB2zyT2AvTssWdwwzK (خاص، لا يفتحه إلا حسابك)

![يومي على iPhone](docs/screenshots/12-day-iphone-ar.png)

## الاستخدام

### أول مرة (مرة واحدة لكل حساب)
1. افتح الرابط على الآيفون في Safari (مسجّلًا الدخول إلى claude.ai).
2. اختر عبارة مرور (10 أحرف على الأقل؛ الأفضل أربع كلمات لا رابط بينها).
3. احفظ **رمز الاستعادة** في مدير كلمات المرور. لن يظهر مرة أخرى.

### جهاز إضافي (اللابتوب)
افتح الرابط نفسه، وأدخل عبارة المرور مرة واحدة. بعدها لا تُطلب.

### يوميًا
- **إضافة:** اكتب في الحقل السفلي واضغط إدخال. يمكن كتابة الوقت معها:
  `قراءة كتاب 20:00-20:30` · `الاتصال بالمورد غدًا 10:00` · `اجتماع الأحد 9:30` · `مشي 18:00 لمدة 45 دقيقة` · `call mom tomorrow 6pm`
  تظهر معاينة صغيرة للوقت المفهوم، ويمكنك الضغط على "تجاهل الوقت" لحفظ النص كما هو.
- **إنجاز:** اضغط الدائرة. ضغطة أخرى تعيدها.
- **تعديل أو نقل:** اضغط المهمة. غيّر اليوم (`اليوم`/`غدًا`/`بعد غد`/تاريخ آخر)، أو الوقت (ضغطة للساعة وضغطة للدقيقة)، أو المدة، أو `قدّم`/`أخّر`. كل تعديل يُحفظ فورًا.
- **التنقل:** الأسهم في الأعلى، أو شريط الأسبوع، أو السحب أفقيًا، أو الضغط على العنوان لفتح تقويم الشهر.
- **المهام المفتوحة من أيام سابقة** تظهر في سطر هادئ في يوم اليوم، وأنت تقرر ما ينتقل.

### على اللابتوب
`n` أو `/` للإضافة · الأسهم للأيام · `t` لليوم · `Esc` للإغلاق.

### إضافته إلى الشاشة الرئيسية للآيفون
في Safari: زر المشاركة ← "إضافة إلى الشاشة الرئيسية". هذا **اختصار** يفتح الصفحة مباشرة. المنصة لا تسمح بـ Service Worker، لذلك لا يعمل كتطبيق PWA كامل يفتح دون إنترنت (التفاصيل في القيود أدناه).

## كيف تعمل المزامنة (باختصار)
كل تعديل يُحفظ أولًا على جهازك (IndexedDB، مشفرًا)، ثم يُرسل مشفرًا إلى قاعدة بيانات الصفحة في claude.ai تحت مسار خاص بحسابك، ويصل إلى أجهزتك الأخرى خلال ثوانٍ عادةً. إن عدّلت المهمة نفسها على جهازين، تُدمج الحقول المختلفة معًا، وإن تعارض الحقل نفسه يظهر الأحدث وتبقى النسخة الأخرى في المهمة لتختار بينهما. دون اتصال يستمر كل شيء، ثم تكتمل المزامنة عند عودة الاتصال. التصميم في [docs/01-analysis.md](docs/01-analysis.md).

## الخصوصية (باختصار)
- التشفير على الجهاز: AES-256-GCM، والمفتاح محمي بعبارة مرورك (PBKDF2-SHA-256، 600,000 تكرار) وبرمز الاستعادة. كل ذلك من Web Crypto API المدمجة في المتصفح.
- الخادم يرى نصًا مشفرًا فقط، إضافة إلى بيانات وصفية: عدد الحزم المشفرة وأحجامها وأوقات تعديلها.
- لا إعلانات، لا تحليلات، لا تتبع، لا خطوط خارجية، لا إشعارات.
- **لا يحميك من:** جهاز مفتوح بيد غيرك، أو عبارة مرور ضعيفة، أو كود معدّل تقدمه المنصة (قيد عام لتشفير الويب).
- نسيت العبارة؟ رمز الاستعادة يعيدها. فقدت الاثنين وكل الأجهزة؟ **لا يمكن لأحد استعادة المحتوى.**

التفاصيل الكاملة في [docs/security.md](docs/security.md).

## الاختبارات
49 اختبار وحدة و 26 سيناريو في متصفح حقيقي (Chromium)، كلها ناجحة، وتغطي اختبارات القسم 16 كاملة. التفاصيل وما لم يُختبر في [docs/testing.md](docs/testing.md).

## القيود الحالية
1. **لا PWA كامل:** منصة Artifacts تمنع Service Workers. يعمل التطبيق دون اتصال بعد فتحه، لكن فتحه من الصفر يحتاج إنترنت وتسجيل الدخول إلى claude.ai.
2. **لا تدوير لمفتاح التشفير** بعد فقدان جهاز (تغيير عبارة المرور ورمز الاستعادة متاحان).
3. **الحذف ناعم:** المهمة المحذوفة تبقى مشفرة داخل حزمتها (حتى يعمل "تراجع" ولا تضيع تعديلات جهاز آخر). لا تنظيف دوري لها بعد.
4. **لم يُجرَّب على iPhone حقيقي ولا على قاعدة claude.ai الحقيقية:** الاختبارات استخدمت Chromium بمقاس iPhone وبديلًا محليًا لقاعدة البيانات بالواجهة نفسها.
5. **صيغة 24 ساعة فقط**، والملاحظة بحد 2000 حرف، والعنوان بحد 300.

## للمطورين
```
src/        الكود (وحدات ES بلا أي حزم خارجية)
  app.js      الواجهة والتشغيل        sync.js    محرك المزامنة (محلي أولًا)
  crdt.js     الدمج دون تعارض          crypto.js  التشفير وإدارة المفاتيح
  parse.js    فهم الوقت في سطر الإضافة  digits.js  تطبيع الأرقام
  remote.js   الطبقة الوحيدة التي تتصل بالخادم
npm run build   →  dist/pocket-time.html (الصفحة المنشورة) و dist/standalone.html
npm test        اختبارات الوحدة
npm run e2e     سيناريوهات المتصفح
```
لنشر نسخة على استضافة خاصة لاحقًا، يكفي استبدال `remote.js` بطبقة لخادم مزامنة يخزن وثائق مشفرة، وإضافة Service Worker. المنطق والتشفير لا يتغيران.
