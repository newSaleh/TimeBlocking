# Pocket Time

مذكرة جيب رقمية لتنظيم اليوم بأسلوب Time Blocking: بسيطة، سريعة، بالعربية والإنجليزية، تعمل دون إنترنت، وتُزامن مهامك المشفرة بين الآيفون واللابتوب.

**الرابط:** https://newsaleh.github.io/TimeBlocking/
(يعمل بعد خطوة التفعيل الأولى أدناه.)

![يومي على iPhone](docs/screenshots/12-day-iphone-ar.png)

## المطلوب منك مرة واحدة

### 1. تشغيل الموقع (دقيقة واحدة)
1. في المستودع `newSaleh/TimeBlocking`: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
2. **Settings ← General ← Default branch**: اختر `main`.
3. من تبويب **Actions** شغّل "Deploy to GitHub Pages" (Run workflow)، أو انتظر أول دفع إلى `main`.

بعدها يعمل الرابط أعلاه، ويتحدث تلقائيًا مع كل تحديث على `main`.

### 2. المزامنة بين الأجهزة (اختيارية، 3 دقائق)
1. أنشئ مستودعًا **خاصًا (Private)** فارغًا، مثلًا `pocket-time-data`.
2. أنشئ **Fine-grained token**: Repository access ← Only select repositories ← اختر المستودع. Permissions ← Contents ← Read and write. اختر مدة صلاحية طويلة.
3. في التطبيق: ⋯ ← **تفعيل المزامنة عبر GitHub**. الصق اسم المستودع والرمز، ثم اضغط **ربط**.
4. اضغط **إلى بريدي** أو **إلى تيليغرام** لترسل لنفسك **رابط الاستعادة**.

### 3. ربط اللابتوب
افتح رابط الاستعادة من بريدك أو تيليغرام على اللابتوب، فتظهر مهامك. لا كلمة مرور.

## الاستخدام اليومي
- **إضافة:** اكتب في الحقل السفلي واضغط إدخال. يمكن كتابة الوقت معها:
  `قراءة كتاب 20:00-20:30` · `الاتصال بالمورد غدًا 10:00` · `اجتماع الأحد 9:30` · `مشي 18:00 لمدة 45 دقيقة` · `call mom tomorrow 6pm`
- **إنجاز:** اضغط الدائرة. ضغطة أخرى تعيدها.
- **تعديل أو نقل:** اضغط المهمة. غيّر اليوم، أو الوقت (ضغطة للساعة وضغطة للدقيقة)، أو المدة، أو `قدّم`/`أخّر`. كل شيء يُحفظ فورًا.
- **التنقل:** الأسهم، أو شريط الأسبوع، أو السحب أفقيًا، أو الضغط على العنوان لفتح تقويم الشهر.
- **اللابتوب:** `n` للإضافة · الأسهم للأيام · `t` لليوم · `Esc` للإغلاق.

## الشاشة الرئيسية للآيفون
في Safari: زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. يفتح بعدها كتطبيق مستقل، ويعمل **حتى دون إنترنت**.

ملاحظة خاصة بالآيفون: التطبيق المضاف إلى الشاشة الرئيسية له تخزين منفصل عن Safari. لذلك افتحه من الأيقونة، ثم: ⋯ ← **لدي رابط استعادة** ← الصق الرابط. بعدها يعمل مربوطًا.

## الإنترنت
- **غير ضروري للاستخدام.** يفتح التطبيق ويضيف ويعدّل دون اتصال، بعد أن تفتحه مرة واحدة على الأقل وهو متصل.
- **ضروري للمزامنة فقط.** التعديلات تُحفظ على الجهاز، وتُرسل تلقائيًا عند عودة الاتصال. تصل إلى الجهاز الآخر خلال ثوانٍ (يتحقق التطبيق كل 10 ثوانٍ، وعند فتحه).

## الخصوصية (باختصار)
- تشفير على الجهاز بـ AES-256-GCM. GitHub يرى ملفات مشفرة فقط.
- لا كلمة مرور. المفتاح على أجهزتك وفي رابط الاستعادة فقط.
- **من يملك رابط الاستعادة يستطيع قراءة مهامك.** إرساله إلى البريد أو تيليغرام سهل، لكن أمانه يصبح بقدر أمان ذلك الحساب.
- فقدت كل الأجهزة؟ افتح رابط الاستعادة وتعود كل المهام. فقدت الرابط وكل الأجهزة؟ لا يمكن لأحد فك المحتوى.

التفاصيل في [docs/security.md](docs/security.md).

## الاختبارات
50 اختبار وحدة و 29 سيناريو في متصفح حقيقي (Chromium)، كلها ناجحة. تشمل: الفتح دون إنترنت، وربط جهاز برابط الاستعادة، والتعارض بين جهازين، وانقطاع الاتصال. التفاصيل في [docs/testing.md](docs/testing.md).

## القيود الحالية
1. **لم يُجرَّب على iPhone حقيقي ولا على GitHub الحقيقي:** الاختبارات استخدمت Chromium بمقاس iPhone ونسخة وهمية من واجهة GitHub بالسلوك نفسه.
2. **المزامنة تحتاج مستودعًا خاصًا ورمز GitHub**، تنشئهما مرة واحدة.
3. **رمز GitHub له تاريخ انتهاء.** عند انتهائه يظهر تنبيه هادئ لتحديثه.
4. **الحذف ناعم:** المهمة المحذوفة تبقى مشفرة داخل حزمتها حتى يعمل "تراجع" ولا تضيع تعديلات جهاز آخر.
5. **صيغة 24 ساعة فقط**، والملاحظة بحد 2000 حرف.

## للمطورين
```
src/        الكود (وحدات ES بلا أي حزم خارجية)
  app.js      الواجهة والتشغيل        sync.js    محرك المزامنة (محلي أولًا)
  crdt.js     الدمج دون تعارض          crypto.js  التشفير ورابط الاستعادة
  parse.js    فهم الوقت في سطر الإضافة  digits.js  تطبيع الأرقام
  remote.js   الاتصال بالخادم (GitHub أو claude.ai)   sw.js  العمل دون إنترنت
npm run build   →  site/ (موقع GitHub Pages)
npm test        اختبارات الوحدة
npm run e2e     سيناريوهات المتصفح
```
النشر يتم تلقائيًا عبر `.github/workflows/pages.yml` عند كل دفع إلى `main`.
