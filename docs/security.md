# الخصوصية والتشفير في Pocket Time

هذا المستند يشرح ما يحميه التطبيق فعلًا، وكيف، وما لا يحميه.

## 1. الملخص

- لا توجد كلمة مرور. عند أول فتح يُولَّد على جهازك **مفتاح خزنة** عشوائي (AES-256).
- كل المهام والملاحظات تُشفَّر به **على جهازك** قبل حفظها أو إرسالها (AES-256-GCM من Web Crypto المدمجة في المتصفح).
- المزامنة عبر **مستودع GitHub خاص** تملكه أنت. GitHub لا يستلم إلا نصًا مشفرًا، ولا يملك المفتاح.
- لنقل المفتاح إلى جهاز آخر، أو لاستعادته بعد فقدان الجهاز: **رابط الاستعادة**. ترسله لنفسك بالبريد أو تيليغرام أو أي وسيلة تختارها.
- لا إعلانات، لا تحليلات، لا تتبع، لا خطوط أو سكربتات من أطراف ثالثة، لا إشعارات. سياسة أمان المحتوى (CSP) في الصفحة تمنعها من الاتصال بأي مكان غير موقعها و `api.github.com`.

## 2. رابط الاستعادة

شكله: `https://newsaleh.github.io/TimeBlocking/#pair=...`

ما بعد `#` يحتوي: مفتاح الخزنة، ومعرّفها، وإعدادات المزامنة (اسم المستودع ورمز GitHub).

- الجزء بعد `#` **لا يُرسل إلى أي خادم ويب** عند فتح الرابط، ولا إلى GitHub Pages. التطبيق يقرؤه على الجهاز ثم يحذفه فورًا من شريط العنوان.
- فتح الرابط على أي جهاز = ربطه بالمهام والمزامنة مباشرة. المهام الموجودة على ذلك الجهاز لا تُحذف، بل تُدمج.
- **من يحصل على الرابط يستطيع قراءة مهامك وتعديلها.** لذلك:
  - لا تشاركه مع أحد.
  - إن أرسلته إلى تيليغرام أو البريد، فأمانه يصبح بقدر أمان حسابك هناك. محادثات تيليغرام العادية ورسائل Gmail **ليست** مشفرة من طرف إلى طرف، فمزود الخدمة يستطيع تقنيًا رؤية الرابط. هذا هو ثمن الاستعادة السهلة، واخترناه بوعي بناءً على طلبك.
  - الأكثر أمانًا: حفظه في مدير كلمات المرور (iCloud Keychain مثلًا) أو في رسالة "المحفوظات" مع تفعيل التحقق بخطوتين لحسابك.

## 3. ما يخزنه كل طرف

| المكان | ما فيه |
|---|---|
| جهازك (IndexedDB) | مفتاح الخزنة، رمز GitHub، ونسخة مشفرة من المهام. |
| مستودع GitHub الخاص | `pt/meta.json` (معرّف الخزنة فقط) و `pt/b/*.json`: حزم مشفرة بالشكل `{v, k, iv, ct}`. لا عناوين ولا أوقات ولا تواريخ ولا المفتاح ولا الرمز. |
| GitHub Pages | كود التطبيق فقط. لا يرى أي بيانات. |
| رابط الاستعادة | المفتاح ورمز GitHub (انظر القسم 2). |

كل حزمة تُشفَّر بـ IV عشوائي جديد في كل حفظ، و **AAD = معرّف الحزمة**. لذلك يُرفض أي نص مشفر عُدّل أو نُقل إلى ملف آخر.

## 4. ما يراه GitHub (بصراحة)

- أن لديك مستودعًا فيه ملفات مشفرة، وعدد الحزم وأحجامها التقريبية.
- وقت كل تعديل: كل حفظ ينشئ commit في المستودع، وهذا يعني أيضًا أن **لديك نسخًا احتياطية تاريخية مشفرة**.
- الشهر الذي أُنشئت فيه كل حزمة (جزء من اسم الملف).

ولا يرى: العناوين، الملاحظات، التواريخ، الأوقات، حالة الإنجاز.

## 5. رمز GitHub

- رمز من نوع **Fine-grained** صلاحيته محصورة في مستودع واحد، و Contents: Read and write فقط. لا يستطيع الوصول إلى مستودعاتك الأخرى ولا حذف المستودع.
- يُخزَّن على أجهزتك وفي رابط الاستعادة، ولا يوجد في كود التطبيق ولا في المستودع العام.
- إن انتهت صلاحيته يظهر سطر هادئ "رمز GitHub لم يعد صالحًا". أنشئ رمزًا جديدًا، والصقه من الإعدادات ← تحديث رمز GitHub، ثم أرسل لنفسك رابط استعادة جديدًا.
- إن تسرب الرمز وحده دون المفتاح: يستطيع صاحبه حذف الملفات المشفرة أو العبث بها، لكن لا يستطيع قراءتها. ألغِ الرمز من GitHub وأنشئ غيره. وتاريخ الـ commits يحفظ النسخ السابقة.

## 6. حدود الحماية

لا يوجد نظام يمنع الوصول "مطلقًا". التشفير **لا** يحميك من:

1. **جهاز مفتوح أو مخترق.** من يملك هاتفك مفتوحًا يرى مهامك.
2. **وصول أحد إلى رابط الاستعادة** (القسم 2).
3. **الثقة في الكود المقدَّم.** الصفحة تأتي من GitHub Pages ومن هذا المستودع. لو تغيّر الكود بسوء نية، يمكنه قراءة ما تكتبه. هذا قيد عام في كل تطبيقات التشفير على الويب. الكود مفتوح ويمكن مراجعته.
4. **ما تخرجه بنفسك.** "تصدير نسخة" ينتج ملف JSON **غير مشفر**. ونص المهمة الذي لم تضفه بعد يُحفظ كمسودة محلية.

## 7. ماذا لو؟

| الحالة | ما يحدث |
|---|---|
| فقدت الآيفون | افتح رابط الاستعادة على الجهاز الجديد، فتعود كل المهام. لمنع الجهاز المفقود من المزامنة: ألغِ رمز GitHub من إعدادات GitHub، وأنشئ رمزًا جديدًا، وأرسل لنفسك رابطًا جديدًا. |
| مسح Safari بيانات الموقع | افتح رابط الاستعادة مرة أخرى. |
| لم أفعّل المزامنة وفقدت الجهاز | المهام كانت على الجهاز فقط ولا يمكن استعادتها. فعّل المزامنة وأرسل الرابط لنفسك مبكرًا. |
| فقدت رابط الاستعادة، وجهاز ما زال يعمل | من الإعدادات على ذلك الجهاز: أرسل الرابط لنفسك مجددًا. |
| فقدت الرابط وكل الأجهزة | المحتوى المشفر في GitHub **لا يمكن لأحد فكه**، ولا حتى أنا (Claude). |
| أريد الاستعادة "عن طريق Claude" | لا أستطيع حفظ مفتاحك: لا أملك ذاكرة أو خادمًا دائمًا بين المحادثات، ولا يُنصح بلصق الرابط في أي محادثة. البريد أو تيليغرام أو مدير كلمات المرور هي الطرق العملية. |

## 8. التحقق

الاختبارات الآلية تتحقق من أن:

- ملفات المستودع بالشكل `{v,k,iv,ct}` أو `{v,kid}` فقط، ولا تحتوي أي عنوان أو وقت، ولا رمز GitHub.
- النسخة المحلية على الجهاز مشفرة.
- أي تعديل على النص المشفر، أو نقله إلى ملف آخر، يُرفض، ومفتاح خزنة آخر لا يستطيع القراءة.
- رابط الاستعادة يعمل من الرابط الكامل أو من الرمز وحده، ويُرفض المدخل غير الصالح.
- لا طلبات شبكة لغير الموقع و `api.github.com`، ولا محتوى مهام في سجلات المتصفح، ولا استدعاء لواجهات الإشعارات.
