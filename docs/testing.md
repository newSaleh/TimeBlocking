# الاختبارات

آخر تشغيل: 15/10/2026. النتيجة: **49/49 اختبار وحدة** و **26/26 سيناريو في المتصفح** نجحت.

```
npm test        # اختبارات الوحدة (Node، دون أي حزم خارجية)
npm run e2e     # بناء الصفحة ثم سيناريوهات المتصفح (Playwright + Chromium)
```

## كيف تُختبر المزامنة دون أجهزة حقيقية؟

- **اختبارات الوحدة:** خادم وهمي في الذاكرة مع اتصال قابل للقطع لكل جهاز، وتأخير عشوائي في التسليم لإثارة حالات السباق.
- **اختبارات المتصفح:** الصفحة المبنية نفسها (`dist/standalone.html`) تُفتح في سياقين من Chromium على **أصلين مختلفين** (`localhost` و `127.0.0.1`)، فلكل "جهاز" تخزين IndexedDB مستقل. بديل اختباري لـ `window.claude.use` (في `e2e/mock-claude.js`) يربطهما بقاعدة بيانات JSON محلية بالسلوك نفسه (وثائق، مسارات، لقطات دورية).
- "الآيفون" يُحاكى بمقاس iPhone SE (375×667، لمس، شاشة عالية الكثافة) على Chromium. **هذا ليس Safari الحقيقي.**

## اختبارات إضافية

- **إغلاق الصفحة قبل المزامنة:** مهمة تُضاف دون اتصال، ثم تُعاد تحميل الصفحة، فتظهر على الجهاز الآخر. ✅
- **حذف على جهاز وتعديل على الآخر دون اتصال:** المهمة تعود ولا يُفقد التعديل. ✅
- **تقارب ثلاثة أجهزة (Fuzz):** 6 جولات × 60 عملية عشوائية مع انقطاعات، وكل الأجهزة تنتهي بالحالة نفسها. ✅
- **خصائص الدمج:** تبادلي، تجميعي، متساوي القوة (200 جولة عشوائية). ✅
- **رمز الاستعادة على جهاز جديد** مع تنسيق فوضوي (أحرف صغيرة، مسافات بدل الشرطات). ✅
- **عبارة مرور بأرقام عربية هندية** على جهاز، وغربية على آخر: المفتاح نفسه. ✅
- **التلاعب بالنص المشفر أو نقله إلى وثيقة أخرى** يُرفض. ✅
- **المفتاح على الجهاز غير قابل للتصدير.** ✅
- **التعارض الزمني** يُعرض كوسم "يتداخل" ولا يمنع الحفظ. ✅
- **المهام المفتوحة من أيام سابقة** تُعرض ولا تُنقل تلقائيًا. ✅
- **لوحة مفاتيح اللابتوب:** `n` للإضافة، الأسهم للأيام، `t` لليوم، `Esc` للإغلاق. ✅
- **التصدير** عبر قدرة التنزيل في المنصة. ✅

## ما لم يُختبر (ويحتاج تجربتك)

1. **Safari على iPhone حقيقي** داخل claude.ai: لوحة المفاتيح، الإيماءات، الأداء، وسلوك التخزين.
2. **قاعدة بيانات claude.ai الحقيقية:** الاختبارات استخدمت بديلًا محليًا بالواجهة نفسها. بعد النشر تأكدت فقط أن المسار الخاص بحسابك موجود وفارغ قبل الاستخدام الأول.
3. **زمن PBKDF2 (600k) على iPhone:** المتوقع أقل من ثانيتين عند الإنشاء أو الفتح فقط.
4. **قارئ الشاشة VoiceOver:** التسميات والأدوار موجودة، لكن لم تُجرَّب بقارئ فعلي.
