# الاختبارات

آخر تشغيل: 15/10/2026. النتيجة: **50/50 اختبار وحدة** و **29/29 سيناريو في المتصفح** نجحت.

```
npm test        # اختبارات الوحدة (Node، دون أي حزم خارجية)
npm run e2e     # بناء الصفحة ثم سيناريوهات المتصفح (Playwright + Chromium)
```

## كيف تُختبر المزامنة دون أجهزة حقيقية؟

- **اختبارات الوحدة:** خادم وهمي في الذاكرة مع اتصال قابل للقطع لكل جهاز، وتأخير عشوائي في التسليم لإثارة حالات السباق.
- **اختبارات المتصفح:** الموقع المبني نفسه (`site/`، كما سيُنشر على GitHub Pages، مع Service Worker) يُفتح في سياقات Chromium على **أصول مختلفة** (`localhost` و `127.0.0.1` و `127.0.0.2`)، فلكل "جهاز" تخزين مستقل. طلبات `api.github.com` تُعترض وتُخدم من نسخة وهمية لواجهة GitHub (`test/fake-github.mjs`) تطبق التحقق من الرمز وتعارض `sha` كما يفعل GitHub.
- "الآيفون" يُحاكى بمقاس iPhone SE (375×667، لمس، شاشة عالية الكثافة) على Chromium. **هذا ليس Safari الحقيقي.**

## اختبارات إضافية

- **الفتح الأول دون أي إعداد أو كلمة مرور.** ✅
- **الفتح من الصفر دون إنترنت** (Service Worker) ثم إضافة مهمة. ✅
- **تفعيل المزامنة:** رسالة واضحة لرمز خاطئ، وقبول رابط المستودع الكامل أو `owner/repo`، ورفض المستودع العام. ✅
- **رابط الاستعادة:** روابط البريد وتيليغرام تحمله، والنسخ يعمل. فتحه على اللابتوب يربطه ويحذف الرابط من شريط العنوان، حتى لو كانت الصفحة مفتوحة أصلًا. ✅
- **جهاز ثالث يحاول ربط المستودع دون الرابط:** يُطلب منه الرابط. بعد لصقه تُدمج مهامه السابقة مع المهام المتزامنة. ✅
- **تعارض كتابة متزامنة على GitHub (sha):** يُدمج ويعاد الإرسال دون فقدان. ✅
- **رمز GitHub منتهٍ:** يظهر كحالة "الرمز غير صالح" لا كانقطاع اتصال. ✅
- **داخل claude.ai** تعمل الصفحة نفسها بالمزامنة عبر قاعدة بيانات المنصة. ✅
- **إغلاق الصفحة قبل المزامنة، والحذف مقابل التعديل، وتقارب ثلاثة أجهزة (Fuzz)، وخصائص الدمج.** ✅
- **التلاعب بالنص المشفر أو نقله إلى ملف آخر يُرفض.** ✅
- **قابلية التثبيت:** الـ manifest والأيقونات و Service Worker موجودة. ✅

## ما لم يُختبر (ويحتاج تجربتك)

1. **Safari على iPhone حقيقي** داخل claude.ai: لوحة المفاتيح، الإيماءات، الأداء، وسلوك التخزين.
2. **GitHub الحقيقي و GitHub Pages:** الاختبارات استخدمت نسخة وهمية من واجهة GitHub بالسلوك نفسه، ولم يُنشر الموقع فعليًا بعد (يحتاج خطوة تفعيل Pages منك).
3. **فتح رابط تيليغرام والبريد على iPhone فعليًا.**
4. **قارئ الشاشة VoiceOver:** التسميات والأدوار موجودة، لكن لم تُجرَّب بقارئ فعلي.
